## Decided design

Settled:

- No `rfc/` directory: the README links to nemarOrg/rfcs, where RFC-0001 lives.
- No `schemas/`, `conformance/` or Python yet; they arrive with B5. So no Ruff hook and no `pyproject.toml` in this card.
- License, decided on 2026-11-18: the World Wide Web Consortium (W3C) Software and Document License for the specification text; Apache License 2.0 for schemas, test vectors, tools and any code. `LICENSE.md` states the three parts (text, software and schemas, contributions); contributions follow the owner's answer to Q8.
- `LICENSE.md` also records the relicensing (owner decision, 2026-11-20): the specification text was first published on docs.nemar.org under CC BY-NC-ND 4.0, and the owner relicensed it to the licenses above on the date of this PR; the format page on docs.nemar.org is removed and replaced by a pointer to this repository (card B3).
- `GOVERNANCE.md`: the owner is the editor; a normative change needs an accepted RFC in nemarOrg/rfcs; editorial changes go by PR review.
  It defines the tag scheme: the major number equals `format_version`; a minor release adds without breaking; a patch is editorial; `-draft.N` marks the text an RFC proposes (for example `3.0.0-draft.1`); `main` carries only accepted text, and an RFC's proposed text lives on a branch until its RFC is accepted.
- Decision records: specification decisions live in this repository's `.context/decisions/`; NEMAR profile and rollout decisions live in nemar-cli; each links the RFC that produced it.
- `AGENTS.md` hard rules, nothing else: published tags and accepted RFCs are immutable; no reader or writer library lives here; vectors come from real recordings under a public-domain dedication (CC0); a normative change needs an RFC; the text has one canonical copy here, and docs.nemar.org links to it without copying it.
- Apply the init-project verdict table in the research note's section 11, except the rows about `rfc/`, Python and `pyproject.toml`.
- `.rules/documentation.md` is rewritten for specification style: RFC 2119 key words, semantic line breaks, abbreviations defined once, American English.
- CI: `text.yml` only, on `pull_request` and `push` to `main`, path filter `**/*.md`, `_typos.toml`, `.github/workflows/text.yml`; `concurrency` cancelling superseded runs; `timeout-minutes: 10`; jobs: spelling with `crate-ci/typos` pinned to a released version, link checking with `lycheeverse/lychee-action` pinned to a released version, and `bun run lint` (Biome over JSON).
  The init-project `test.yml` (which ignores `**.md` and triggers on `develop`) is not used.
- One integration branch, `main`; releases are tags made by the owner.
- `CITATION.cff` names the owner as author and the title "biosig-zarr specification".
- First ADRs in `.context/decisions/`: 0001 license and contribution terms; 0002 no library in this repository; 0003 RFCs live in nemarOrg/rfcs. Each cites nemar-cli's ADR 0128 by content, not by plan numbers.
- Labels are not created by this card (an owner act).

The implementer may choose: README wording, issue template wording, and how the license texts are fetched (from w3.org and apache.org, recorded in the report).
