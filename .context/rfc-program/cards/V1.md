## Decided design

Settled: measure these, in this order:

1. Version DOIs in total, and by prefix (`nm`, `on`, `xx`): `SELECT substr(dataset_id,1,2) AS prefix, count(*) FROM dataset_versions WHERE doi IS NOT NULL GROUP BY prefix` (confirm the table and column names from `backend/src/db/migrations/` first).
2. Datasets by number of versions, and mirrors by their highest major number.
3. Mirror versions that are `N.0.0` with a recorded `source_version`, and mirrors with no known upstream tag (`nemar admin upstream-status --json`).
4. A sample of origins: 15 `nm` and 15 `on` public datasets with more than one version, chosen with a fixed seed from the public API list (`https://api.nemar.org/datasets`), and for each tag the producing pull request (`gh api repos/nemarDatasets/ID/commits/SHA/pulls`) and its author, classified as source, NEMAR, community or unknown by the rules in research section B6; unknown is never guessed.
5. Datasets reporting Hierarchical Event Descriptors (HED), re-measured from the public API.

The implementer may choose: the script language (Bun TypeScript or a shell pipeline) and the seed.
