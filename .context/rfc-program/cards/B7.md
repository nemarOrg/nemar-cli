## Goal

On nemarOrg/biosig-zarr `main`, no file names the Neuroelectromagnetic Data Archive and Tools Resource (NEMAR) as the party that decides, owns or holds the specification;
NEMAR appears only as the text's origin (first published on docs.nemar.org), as its first implementer and profile, as the source of the conformance recordings, and as the host and venue the owner keeps (Q40, Q41);
the copyright holder of the text is "the biosig-zarr contributors";
and a new ADR 0005 records the independence, ready to be released as `2.0.2` (step O4e).
