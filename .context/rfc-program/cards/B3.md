## Decided design

Settled:
`spec-pin.json` holds `{ "repo": "nemarOrg/biosig-zarr", "tag": "2.0.0", "path": "spec/index.md", "sha256": "..." }` with the real digest.
`scripts/fetch-spec.ts` fetches the file at the tag, refuses to write when the digest differs (exit non-zero, naming both digests), and writes the page with the Starlight front matter the current page has (title, description, the "Pre-beta" badge in the sidebar stays in `astro.config.mjs`), followed by a notice: the text's license (W3C Software and Document License), the canonical source and tag with links, and that this page is a rendering.
The fetch URL's base is overridable by `SPEC_FETCH_BASE` so tests use a `Bun.serve` stand-in.
The build fails when the fetch fails; there is no cached fallback.
Plus whatever Q12's answer adds.
The implementer may choose: the notice's wording and where it sits on the page (top or bottom).

## Acceptance

`bun test scripts/fetch-spec.test.ts` passes with three named cases against the stand-in: a matching digest writes the page; a mismatched digest exits non-zero and writes nothing; an unreachable server exits non-zero.
`bun run build` exits 0 and the built page for `formats/biosig-zarr` contains the string `W3C Software and Document License`.
`git ls-files src/content/docs/formats/biosig-zarr.md` prints nothing.

## Gates
