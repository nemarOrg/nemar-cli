## Decided design

Settled:
- **Apply the screen's own functions:** `scanPaths` per path, and `formatCoverage`.
  Do not copy their regexes.
- **For each request, the blocker set:**
  - each non-date finding kind;
  - each unscreened format;
  - whether a flagged path is in HEAD, only in history, or both.
- **Image and document groups**, using word-boundary token matching on the basename:
  - by location: root, `sourcedata/`, `stimuli/`, `derivatives/`, `code/`, `docs/` or `doc/`, `sub-*/`, other;
  - by extension;
  - by name class: `consent`, `questionnaire`, `form` (as a whole word), `photo`/`face`, `figure`/`fig`, `logo`, `manual`, `montage`/`layout`/`cap` (whole word), `screenshot`, or other.
- **Files with no extension and `.other`:** group them by parent directory pattern, with digits replaced by `#` (for example `sourcedata/sub-#/nirs/`).
  Report the 20 most common patterns.
  Never print a basename.
- **Blocked requests:** count them by `block_reason`, and for `min_requirements_failed` by each reason code, from `min_requirements_reasons` in the queue file.
- **What-if table:** for each candidate acknowledgment group, the number of requests whose blocker set would then be empty, or reduced to unread formats only.
- **Leaks:** never print a path that holds a subject label `labelIsNameLike` flags; count it instead.

The implementer may choose: the script structure and the report wording.
