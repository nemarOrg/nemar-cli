## Goal

Several formats are screened by readers that never load signal arrays:
- `.set` files, classic MAT v5 and v7.3, with the `.fdt` companion check;
- `.nirs` (Homer2), which is MAT v5;
- generic `.mat` files.

This affects 104 queued datasets with `.mat`, 24 with `.nirs` and 12 with `.set`.

## Context

- MAT v5 is a 128-byte header followed by data elements.
  Data elements are `miMATRIX`, and `miCOMPRESSED` (zlib), which wraps an `miMATRIX`.
  The reference is the MathWorks "MAT-File Format" PDF, version 7, Level 5.
- A v7.3 file is HDF5 with a 512-byte user block.
  Use A3's `shared/hdf5-meta.ts` for it; MATLAB strings there are `uint16` char arrays with the `MATLAB_class` attribute `char`.
- **EEGLAB fields** that carry text:
  - `subject`, `setname`, `filename`, `filepath`, `comments`, `group`, `condition` and `session`;
  - `history`, which often holds local paths and commands;
  - `etc.*`;
  - `datfile` or `data` as a string naming the `.fdt`;
  - `event[].type` and `urevent[].type`;
  - `chanlocs[].labels`.
  - Read `biosigio`'s `eeglab.py` `_extract_metadata` as prior art for field names only; do not port its loader.
- **Homer2 `.nirs`:** `SD` struct (labels, units), `t`, `d`, `s` and `aux`, which are numeric and skipped, and sometimes `subject` or `notes`.
- A1 defines the `RangeSource` limits.

## Scope

A new `shared/mat-meta.ts` (the MAT v5 walker), new `shared/readers/eeglab.ts`, `shared/readers/homer-nirs.ts` and `shared/readers/mat-generic.ts`, their registration, new finding kinds with `KIND_COPY` entries, tests and fixtures.

## Decided design

Settled:
- **MAT v5 walker:**
  - It walks struct, cell and char arrays.
  - A numeric array of more than 64 elements is skipped by its declared byte size, without reading it.
  - An `miCOMPRESSED` element is stream-inflated and discarded past what is needed; inflation is capped at 256 MiB per file, beyond which the read is `partial` with reason `limit`.
  - Sparse, object and function-handle classes are recorded as `unsupported-datatype` and skipped.
  - The walk is bounded at 20,000 elements and depth 32.
- **v7.3** dispatches to A3, with the same field semantics, and maps A3's incomplete reasons through A4's `shared/readers/hdf5-incomplete.ts`.
- **EEGLAB rules:**
  - `subject` follows the same rule as SNIRF `SubjectID`: a name-like value is `eeglab-subject-name` (identifier), other free text is `eeglab-subject-freetext` (review), and the BIDS label or a short code is no finding.
  - `filepath` and `history` are not scanned for paths: they record the researcher's machine and name no participant (design review, 2026-11-25).
    `history` goes through the name-like rule only.
  - `comments` and `etc` free text go through the free-text rules.
  - Event types go through the name-like rule only, as `eeglab-event-name` (review); numeric and code-like types never fire.
  - Channel labels never fire.
- **`.fdt` companion:**
  - The named `datfile` must be a sibling in the same directory, and the name must be safe (no `..`, no separator).
  - A miss is `companion_missing`, not a finding.
  - An `.fdt` file is never read.
- **Homer `.nirs`:** string fields go through the free-text rules.
- **Generic `.mat`:** every char array goes through the free-text rules, under reader `mat`.

The implementer may choose: the walker's internals, and how compressed elements are streamed.

## Acceptance

- **False-positive gate (owner rule).**
  Run the reader over at least 200 public files of its format.
  Get them from OpenNeuro's public bucket (`aws s3 cp --no-sign-request s3://openneuro.org/<ds>/...`, headers or metadata only where the format allows a ranged read) or from PhysioNet open data.
  Report the findings per kind per 100 files in the PR.
  - Identifier-severity findings must be 0, or each one is explained without its value.
  - Review-severity findings must be at most 5 per 100 files.
  - The script is `scripts/dev/reader-fp-measure.ts` (shared; create it if absent).
  - The downloaded files stay in the OS temp directory and are deleted afterwards.

- **Fixtures:** real public files with provenance and license recorded.
  - a classic `.set` paired with its `.fdt`;
  - a classic `.set` with its data embedded;
  - a v7.3 `.set`, reusing A3's;
  - a Homer2 `.nirs`;
  - one generic `.mat`.
  - Add edited copies that hold a made-up name in `subject` and a home-directory path in `filepath`, and record the edits.
- `bun test test/mat-meta.test.ts test/readers-eeglab.test.ts test/readers-homer-nirs.test.ts test/readers-mat-generic.test.ts test/identifier-fleet.test.ts` passes.
- **Bounds:**
  - For an uncompressed `.set` with embedded data, no read range overlaps the `data` element's payload.
  - A compressed file is inflated only up to the cap, asserted with a cap lowered for the test.
  - Report, for the real fixtures, how many come out `partial` because `data` precedes the metadata.
- A missing `.fdt` gives `companion_missing`; a truncated file gives `partial`.
- A revert check per new rule.
