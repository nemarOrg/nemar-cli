## Goal

For a dataset, one shared resolver finds its upstream sources, fetches each source's license from DataCite, Crossref or OpenAlex, and returns a compatibility outcome.
Each outcome comes with evidence URLs, a remedy and a docs anchor.
The depositor can reproduce the same outcome locally with `nemar dataset license-check <path>`.

## Decided design

Settled:
- **Sources, in order, de-duplicated:**
  - `SourceDatasets[].DOI` and `.URL` from `dataset_description.json`;
  - enrichment `related_identifiers` of type `IsDerivedFrom` or `IsIdenticalTo`;
  - DOIs and known repository URLs in `attestation_upstream_source` and the README.
- **Known URL forms map to DOIs:**
  - OpenNeuro `ds\d{6}` with a version becomes `10.18112/openneuro.<ds>.v<ver>`; with no version, use the concept record from DataCite.
  - PhysioNet `physionet.org/content/<slug>/<ver>` uses its DataCite DOI from the landing metadata.
  - Zenodo `records/<n>` becomes `10.5281/zenodo.<n>`.
  - figshare and OSF DOIs are taken as they are.
- **Fetch order for each DOI:**
  - DataCite `https://api.datacite.org/dois/<doi>` (`attributes.rightsList[].rightsIdentifier`, `rightsUri`);
  - then Crossref `https://api.crossref.org/works/<doi>` (`message.license[].URL`);
  - then OpenAlex `https://api.openalex.org/works/doi:<doi>` (`primary_location.license`, then `locations[].license`).
  - Stop at the first license found, and record which resolver answered and its evidence URL.
  - Per-source timeout 8 s, and at most 10 sources per dataset.
- **License normalization:** a closed set of `cc0`, `cc-by`, `cc-by-sa`, `cc-by-nc`, `cc-by-nc-sa`, `cc-by-nd`, `cc-by-nc-nd`, `odc-by`, `odbl`, `pddl`, `physionet-credentialed`, `restricted`, `other` and `none`.
  It maps from SPDX ids, Creative Commons URIs (any version) and free text, through one table.
- **Outcomes,** a closed union, each with a `Copy = { statement; read; remedy; anchor }` in the module's copy table:
  - `compatible`: every source permits the target license;
  - `compatible_nc`: an NC source, with NC carried into the target;
  - `needs_permission`: an ND, restricted, credentialed, `none` or `other` source, or an NC source with a target that drops NC;
  - `share_alike_mismatch`: an SA source with a target that is not SA;
  - `no_upstream`: no source was found, and the dataset is original;
  - `unresolved`: a source that could not be fetched or parsed.
    It is never treated as compatible.
- **Result:** `{ outcome, target_license, sources: [{ id, resolver, license, raw, evidence_url, status }], resolver_version, fetched_at }`.
  Print it the same way in the CLI and in the admin command.

The implementer may choose: the module's internal structure, and the free-text license patterns beyond the obvious ones.
