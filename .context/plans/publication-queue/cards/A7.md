## Goal

A measured table of which image and document files hold 229 queued requests in "needs review", grouped so the owner can choose a policy for each group.

## Context

- The rule is in `shared/identifier-scan.ts`, `scanPaths`: `IMAGE_OR_DOCUMENT` and `BIDS_PHOTO`, near line 1073.
- The 229 dataset ids are in `.context/plans/publication-queue/a7-dataset-ids.txt`, measured 2026-11-25.
- Read each dataset's file tree read-only, with the default branch's tree:
  `gh api "repos/nemarDatasets/<id>/git/trees/HEAD?recursive=1" --jq '.tree[] | select(.type=="blob") | .path'`.
  Some repositories are private; the `gh` login has read access.
  Read paths only, never file contents.
- Recall the privacy concern behind the rule: a photograph can show a face, and a document can be a signed consent form, a questionnaire or a clinical record.
  Figures, stimuli, logos and device manuals are usually harmless.

## Scope

A new `.context/plans/publication-queue/a7-image-document-report.md`, a script `scripts/dev/measure-image-document.ts`, and a JSON output beside the report.
The JSON holds counts and path patterns only.
No product code.

## Decided design

Settled:
- **Apply the rule:** apply the exact current rule by importing `scanPaths` from `shared/identifier-scan.ts`; do not copy the regex.
- **Group each flagged path by:**
  - location: root, `sourcedata/`, `stimuli/`, `derivatives/`, `code/`, `docs/` or `doc/`, inside `sub-*/`, other;
  - extension;
  - a name class: contains `consent`, `questionnaire`, `form`, `photo` or `face`, `figure` or `fig`, `logo`, `manual`, `montage`, `layout`, `cap`, or `screenshot`; or matches a BIDS `_photo` that `BIDS_PHOTO` missed; or other.
- **The report holds:**
  - one table of groups with counts of files and of datasets;
  - the 20 most common basenames with digits replaced by `#`;
  - the number of datasets that would leave "needs review" under each of three candidate policies.
- **The three candidate policies:**
  - (P1) Exempt `stimuli/`, `derivatives/`, `code/` and figure-named files; keep the rest flagged.
  - (P2) P1, plus exempt files under 200 KiB that are named `montage`, `layout`, `cap` or `logo`.
  - (P3) Keep the rule as it is, and give admins a batch acknowledgment per group.
- **No path is printed** if it contains a subject label that `labelIsNameLike` flags; count it instead.

The implementer may choose: the script structure and the wording of the report.
