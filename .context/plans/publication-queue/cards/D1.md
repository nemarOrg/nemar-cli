## Goal

For a dataset, one shared resolver finds its upstream sources and fetches each source's license and resource type from DataCite, Crossref or OpenAlex.
It returns a compatibility outcome with evidence URLs, a remedy and a docs anchor.
A depositor reproduces the outcome with `nemar dataset license-check <path>`, and an administrator reads it with `nemar admin dataset license-lineage <id>`.

## Decided design

Settled:
- **Sources**, in this order and de-duplicated:
  - `SourceDatasets[].DOI` and `.URL` from `dataset_description.json`;
  - enrichment `related_identifiers` of type `IsDerivedFrom` or `IsIdenticalTo`;
  - DOIs and known repository URLs in `attestation_upstream_source` and the README.
- **URL forms mapped to DOIs:**
  - OpenNeuro `ds\d{6}` with a version becomes `10.18112/openneuro.<ds>.v<ver>`; without a version, the latest version record from DataCite.
  - Zenodo `records/<n>` becomes `10.5281/zenodo.<n>`.
  - A PhysioNet `content/<slug>/<ver>` URL uses its DataCite DOI.
  - figshare and OSF DOIs are used as they are.
- **Fetch order for each DOI:**
  1. DataCite `https://api.datacite.org/dois/<doi>`: `rightsList[]` and `types.resourceTypeGeneral`.
  2. Then Crossref `https://api.crossref.org/works/<doi>`: `license[]` and `type`.
  3. Then OpenAlex `https://api.openalex.org/works/doi:<doi>`: `primary_location.license` and `type`.

  Stop at the first answer.
  Each fetch has an 8 s timeout, and a dataset has at most 10 sources.
  Fetches are cached per DOI for 24 hours in the Worker cache.
- **Filtered out before use:**
  - access-rights URIs (`info:eu-repo/semantics/*`);
  - Crossref TDM and `stm-asf` licenses;
  - licenses whose `content-version` is not `vor` or `unspecified`.
- **A record that is not a dataset** (a resource type other than `Dataset`, or a Crossref or OpenAlex type that is an article) gives `source_is_publication`.
  An article's license is not the data's license.
- **Normalized licenses**, a closed set mapped from SPDX ids, Creative Commons URIs (any version) and free text through one table:
  `cc0`, `pddl`, `cc-by`, `odc-by`, `cc-by-sa`, `odbl`, `cc-by-nc`, `cc-by-nc-sa`, `cc-by-nd`, `cc-by-nc-nd`, `physionet-credentialed`, `physionet-restricted`, `restricted`, `other`, `none`.
- **Outcomes**, a closed union, combined over all sources on a restriction lattice where the most restrictive wins:
  - `compatible`: every source is `cc0` or `pddl`.
  - `compatible_attribution`: there is a BY or ODC-By source.
    The remedy requires `IsDerivedFrom` and credit in the README; a CC0 target is allowed, but attribution persists.
  - `compatible_nc`: there is an NC source and the target carries NC.
  - `share_alike_mismatch`:
    - an SA source with a target that is not SA, or SA of an earlier version;
    - `odbl` with a target that is not ODbL.
  - `needs_permission`, any of:
    - an ND source;
    - `restricted`, `other` or `none`;
    - an NC source whose target drops NC;
    - an incompatible pair of sources (NC with a non-NC SA source; ODbL with CC-BY-SA).
  - `redistribution_prohibited`: a `physionet-credentialed` or `physionet-restricted` source.
    The remedy names the source's own permission; the depositor cannot grant it.
  - `source_is_publication`: as above, needs permission.
  - `no_upstream_declared`: no source was found.
    The remedy asks for the attestation; nothing is inferred.
  - `unresolved`: a source could not be fetched or parsed.

  `unresolved` is never compatible, and no outcome here ever denies automatically (ADR 0139).
- **Result:** `{ outcome, target_license, sources: [{ id, resolver, resource_type, license, raw, evidence_url, status }], resolver_version, fetched_at }`.
  The CLI and the admin command print it the same way, using the copy table.
- **Exit codes** of `license-check`:
  - 0 for `compatible`, `compatible_attribution` and `compatible_nc`;
  - 2 for every other outcome.

The implementer may choose: the module structure, and the free-text license patterns beyond the obvious ones.
