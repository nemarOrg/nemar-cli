## Goal

A report the owner reviews before any dataset pull request: for each of the 167 public iEEG datasets, what the pipeline would write, refuse or leave for a human, with the numbers behind each decision.

## Context

- The dataset list is the census in `census.csv` beside the plan (all 167 ids). Run `python -m ieeg_geometry run <id>` (P1) without `--apply` for each, with a shared fetch cache under the scratchpad, never inside the repository.
- Read-only: no `--apply`, no pushes to any dataset, no uploads.

## Scope

`.context/plans/ieeg-geometry/r1-report.md` (the summary) and `.context/plans/ieeg-geometry/r1/` (one report JSON per dataset, committed only if the folder stays under 5 MB; otherwise commit the summary and a compressed archive under 5 MB). Nothing else.

## Decided design

Settled:
- The summary has: totals per decision and per track; the datasets that would gain template positions, the subjects and files, and the evidence grade mix; every needs-human item with its reason, grouped; every refusal reason with counts; the subject-surface count; the one-time N.0.1 list (mirrors that would get a version) and the PR list (`nm` datasets); the measured threshold margins (for each written set the distance to its threshold, and the closest calls); anything surprising.
- It reads every risk row in the plan and says what the run shows for each.
- It contains no host names or private paths.

The implementer may choose: the summary's table layout.

## Acceptance

- All 167 ids attempted; the summary lists any that failed to run, with the error.
- The summary's totals match the per-dataset JSON (a small script you commit under `scripts/ieeg_geometry/tools/` recomputes them; quote its output).

## Gates

`cd scripts/ieeg_geometry && uv run ruff check tools/ && uv run ruff format --check tools/`.

## Stop conditions

- The run would write or push anything.
- More than 20 datasets fail to run for the same reason (report the reason after the first few; it is a P1 bug).

## Report

Your final message is the report, at most 25 lines: PR number (into `epic/ieeg-geometry`) and head commit hash; the headline totals; the closest threshold calls; the failures; questions for the owner.
