## Goal

A tested Python package `ieeg_geometry` in `scripts/ieeg_geometry/` that reads a BIDS iEEG dataset checkout's electrode files and subject surfaces, measures how well contacts fit a reference surface, and records pipeline-owned files, so tracks C, B and A build on one set of readers and one verifier.

## Decided design

Settled:
- Layout: a uv project at `scripts/ieeg_geometry/` (`pyproject.toml`, `uv.lock`, package `ieeg_geometry/`, tests in `tests/`), Python 3.12, dependencies limited to numpy, scipy and nibabel.
- `bids.py`: discover every electrodes and coordsystem pair per subject, session and `space-` entity; parse `electrodes.tsv` (`n/a` and `NaN` are missing; rows with missing x, y or z are kept and flagged); convert `iEEGCoordinateUnits` `m`, `cm`, `mm` to millimeters and refuse anything else with a named reason; return the contact type per contact from the `type` column, else from the matching `channels.tsv` (`SEEG`, `ECOG`, `DBS`), else unknown.
- `surfaces.py`: read FreeSurfer binary triangle surfaces including the `volume info` footer's `cras` (c_ras); GIfTI with ASCII, Base64Binary and GZipBase64Binary encodings and both `ArrayIndexingOrder` values (column-major is real: on004457); MATLAB v5 structs with `vert`/`tri` (or `Vertices`/`Faces`) fields; one `Surface` type (vertices in mm, faces, hemisphere if known, source path, c_ras if known). A MATLAB v7.3 file is refused with a named reason.
- `reference.py`: the vendored references, loaded by name: `fsaverage` (fsaverage6 pial, both hemispheres, from FreeSurfer's distribution, stored as compressed `.npz` with `LICENSE` and `SHA256SUMS`) and `MNI152NLin2009cAsym` (the website's `brain-mesh v1` files, copied with their license, read by a `brain-mesh v1` reader here). If FreeSurfer's license does not allow redistributing fsaverage6, STOP (see Stop conditions).
- `verify.py`: `fit(contacts_mm, surface, contact_type) -> Fit` with the median, 90th percentile and maximum nearest-vertex distance (scipy `cKDTree`), the count used, and `passed` under the plan's thresholds: ECoG median at most 2.0 mm; sEEG median at most 6.0 mm and at least 95 percent of contacts inside the closed pial surfaces (point-in-mesh by ray parity, both hemispheres); unknown type uses the sEEG rule. Also `fit_with_offset(..., c_ras)` that tries as declared and with c_ras added and reports both.
- `ownership.py`: read and write `.nemar/ieeg-geometry.json` (`schema: 1`, `pipeline_version`, and one entry per owned path with `kind`, `inputs` as path plus git blob id, `method`, and `verification` as the `Fit` fields plus the reference name); writing is deterministic (sorted keys, stable order) so a rerun on unchanged inputs produces identical bytes.
- `__main__.py`: `uv run --project scripts/ieeg_geometry python -m ieeg_geometry inspect <dataset-dir>` prints, per subject and electrodes file: frame, units, contact count by type, and the fit against each reference and against each subject surface found, as declared and with c_ras. Read-only.

The implementer may choose: internal function names beyond those above, fixture construction, and how the point-in-mesh test handles degenerate rays (document it).

## Acceptance

- `uv run --project scripts/ieeg_geometry pytest -q` passes, with tests that each fail without the code they cover, including:
  - a GIfTI column-major fixture read correctly (a row-major read of the same file gives a wrong extent and the test proves the difference);
  - a FreeSurfer surface whose c_ras footer is read, and `fit_with_offset` choosing the offset where the as-declared fit fails;
  - meters converted to millimeters (an on004473-style value);
  - contacts placed on fsaverage6 vertices pass against `fsaverage` with median 0.0 mm and fail against `MNI152NLin2009cAsym` or after a 20 mm shift;
  - on004457 sub-2's native electrodes fit its shipped right-hemisphere surface better than its `space-ACPC` electrodes (from the census: about 9.9 mm median for the ACPC file), using a cut-down fixture of the real surface;
  - `.nemar/ieeg-geometry.json` round trip is byte-identical on rerun.
- `uv run --project scripts/ieeg_geometry python -m ieeg_geometry inspect <fixture dataset dir>` runs on a committed mini-dataset fixture and its output is quoted in the PR.

## Stop conditions

- FreeSurfer's license does not clearly allow redistributing the fsaverage6 surface: stop before committing it and report the license text you read.

- Any reader needs a dependency beyond numpy, scipy and nibabel.
- The thresholds in Decided design reject the census's verified same-frame cases on the real fixture data you test.
