## Goal

Every word, prefix, header, number and request and response shape of protocol `nemar.runner.v1` exists once in `shared/`, with a JSON Schema nemar-process copies byte for byte, and tests hold zod and the schema to each other.

## Context

- Read ADR 0118 decisions 10 and 12, `.context/compute-program/implementation-notes.md` section 6, `shared/compute-state.ts`, `shared/contract/compute-launch.ts` with `compute-launch.schema.json` and the test that holds them (`grep -l "compute-launch.schema.json" test backend/test`).
- `LAUNCH_SPEC_ENV_MAX_CHARS` and `decodeLaunchSpecEnv` exist; a claimed job carries that value.

## Scope

- `shared/compute-state.ts`; new `shared/contract/compute-runner.ts` and `shared/contract/compute-runner.schema.json`; `shared/contract/index.ts`; new `test/compute-runner-contract.unit.test.ts`; existing tests that count platform failure codes or words.
- Nothing in `backend/` or `src/`.

## Decided design

Settled:
- Words: `COMPUTE_EXECUTORS = ["tapis", "runner"]`; `COMPUTE_ACCOUNTING = ["su", "none"]`; `RUNNER_BACKENDS = ["local", "slurm"]`; `RUNNER_PHASES = ["started", "uploading"]`; `RUNNER_ARCHES = ["amd64", "arm64"]`; `RUNNER_RUNTIMES = ["apptainer", "docker", "podman"]`; `RUNNER_TRUST = ["lab", "hpc"]`; `RUNNER_PROTOCOL = "nemar.runner.v1"`.
- `runner_lost` is the thirteenth platform failure code with details `lease_expired`, `claims_exhausted`, `deadline_exceeded`, `runner_revoked`; `isPlatformFailure("runner_lost", d)` is true for each.
- `RUNNER_REFUSALS` and statuses: `runner_credential_not_accepted` 401, `runner_unknown` 401, `runner_token_expired` 401, `runners_disabled` 503, `lease_lost` 409, `job_not_claimed` 404, `runner_outdated` 426, `protocol_unsupported` 426, `runner_accounting_unbuilt` 409, `invalid_body` 400.
- Prefixes `RUNNER_SECRET_PREFIX = "nmr_"`, `RUNNER_ACCESS_PREFIX = "nmra_"`, each plus exactly 64 lowercase hex; `RUNNER_ID_RE = /^rnr_[0-9a-f]{24}$/`; `LEASE_ID_RE = /^[0-9a-f]{32}$/`; `RUNNER_SITE_RE = /^[a-z0-9_]{1,32}$/`; header `RUNNER_LEASE_HEADER = "X-Compute-Lease"`; `RUNNER_USER_AGENT_PREFIX = "nemar-runner/"`.
- Numbers: `RUNNER_LEASE_SECONDS = 600`, `RUNNER_HEARTBEAT_SECONDS = 60`, `RUNNER_ACCESS_TOKEN_SECONDS = 900`, `RUNNER_MAX_CLAIMS = 3`, `RUNNER_LOST_GIVE_UP_MINUTES = 60`, `RUNNER_DEADLINE_GRACE_MINUTES = 15`, `RUNNER_SWEEP_BATCH = 10`, `RUNNER_MAX_FREE_SLOTS = 32`.
- Requests (strict): `RunnerRegisterRequestSchema {name (word, 1-64), pool ("cpu"|"gpu"), cores (1-256), memory_mb (1-16777216), gpus (0-8), scratch_gb (1-100000), backend, runtimes (1-3, unique), arch, accounting, site, trust}`; `RunnerTokenRequestSchema {protocol (literal RUNNER_PROTOCOL), runner_version (semver, at most 32)}`; `RunnerClaimRequestSchema {protocol, free_slots (1-32), runtimes, arch, runner_version}`; `RunnerHeartbeatRequestSchema {job_id, lease_id, phase}`; `RunnerCompleteRequestSchema {job_id, lease_id, exit_number (0-255), launcher_failure_code (a launcher code word or null), launcher_detail (word or null), usage {wall_seconds, cpu_seconds, max_rss_mb} (non-negative safe integers), usage_partial (boolean), scratch_discarded (boolean)}`.
- Responses (passthrough): `RunnerRegisterResponseSchema {runner_id, secret}`; `RunnerTokenResponseSchema {access_token, expires_at}`; `RunnerClaimResponseSchema {jobs: [{id, lease_id, lease_expires_at, launch_spec_env, image {uri, digest, sif}, cores, memory_mb (nullable), gpus, minutes}] (0 to free_slots), min_runner_version}`; `RunnerHeartbeatResponseSchema {lease_expires_at, cancel}`; `RunnerCompleteResponseSchema {state}`.
- JSON Schema: one `$defs` entry per shape, `$id` `https://api.nemar.org/schemas/compute-runner-v1.json`, requests `additionalProperties: false`, responses open, ASCII only.
The implementer may choose: helper names, `$defs` order, test structure.

## Acceptance

- `bun test test/compute-runner-contract.unit.test.ts` passes, with cases that accept a valid instance of every request, refuse an unknown key in every request, accept an unknown key in every response, refuse a secret or token one hex short or uppercase, refuse a claim answer with more jobs than `RUNNER_MAX_FREE_SLOTS`, and agree between zod and the JSON Schema (the launch-spec test's validator) on at least 40 generated instances.
- Each test fails under a one-line mutation (listed).
