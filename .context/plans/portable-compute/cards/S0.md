Plan: .context/plans/portable-compute/checkpoints.md, row CP-2 ("the demo runner registration revoked and the local stack's state deleted; `$RUNNER_ROOT` removed on the demo workstation")

## Goal

After the demo, nothing of F1 is left running or holding a credential: the demo runner registration is revoked in the local stack, the stack and the reverse tunnel are stopped, the stack's state (which holds keys) is deleted, and `$RUNNER_ROOT` and the runner's configuration are gone from the demo workstation, while the evidence the demo brief cites stays untouched.

## Context

- Live facts from the manager: `$WS_DEMO` (workstation B's alias), `$RUNNER_ROOT`, DM-15's operator scratch directory (`<operator scratch>/dm15/`, holding `stack/`, `cfg/`, `out/`, `run.typescript`, `README.txt`), the runner id DM-15 registered, and the names of the detached sessions that run the stack and the tunnel.
- The demo assets are frozen: the brief cites the transcripts, logs and job record in the evidence directory, never the stack's state. Never delete or edit `README.txt`, `run.typescript`, `out/`, DM-19's evidence or DM-14's evidence.
- Docker's image cache on the workstation stays as it is (the brief says the image stays cached on purpose; later cards pull their own image).
- Workstation B is shared with other people's work (owner, 2026-11-14; `cp2-note-N.md`), and its GPU is often busy during deadlines. This card starts no job, no container and no GPU process, ever; it only stops and deletes what the demo created, which frees resources, so it proceeds on a busy machine, with its deletions at the lowest priority. Its step 1b is the first recorded reading of how busy the machine and its GPU are, which later cards' idle checks are compared with.

## Scope

- The operator's machine: DM-15's `stack/` and `cfg/` directories and the two detached sessions. Workstation B: `$RUNNER_ROOT`, `~/.config/nemar-runner/`, the runner process and containers labeled with DM-15's runner id, and the read-only machine and GPU readings of step 1b. Nothing else, and never the Zarr converter's directories or the other workstation.

## Decided design

Settled, in order:
1. `date`; if earlier than 2026-11-15T12:00-08:00 and the owner has not said the demo ended, stop.
1b. The machine reading, after the date check and before any teardown, into `<operator scratch>/s0/machine-before.txt`: `ssh "$WS_DEMO" 'read l1 rest < /proc/loadavg; echo "load1=$l1 cpus=$(nproc) mem_avail_mb=$(( $(sed -n "s/^MemAvailable: *\([0-9]*\) kB$/\1/p" /proc/meminfo) / 1024 ))"; for i in 1 2 3 4 5 6; do echo "apps=$(nvidia-smi --query-compute-apps=pid --format=csv,noheader 2>/dev/null | grep -c .) gpu=$(nvidia-smi --query-gpu=index,memory.used,utilization.gpu --format=csv,noheader,nounits 2>/dev/null | tr -d " ")"; sleep 5; done'` (counts and numbers only: no process id, name or user). Record whether any sample shows GPU memory in use above 1024 MiB with `apps=0` (a sign that the runner's account cannot see other accounts' GPU processes; a finding for card L3). Busy or idle, go on: this card starts nothing.
2. `ls -l <operator scratch>/dm15/README.txt <operator scratch>/dm15/run.typescript && ls <operator scratch>/dm15/out | head`: the evidence exists outside `stack/`; else stop.
3. Revoke in the stack, with the stack's stored owner key (never printed): `TEST_API_URL=http://127.0.0.1:8787 NEMAR_CONFIG_DIR=<operator scratch>/dm15/cfg NEMAR_NO_UPDATE_CHECK=1 bun run src/index.ts admin compute runners revoke <runner id> --json`, then `admin compute runners list --json` shows it revoked. If the stack is no longer answering, record "stack already down" and go on.
4. On `$WS_DEMO`: `pgrep -u "$(id -u)" -f nemar_runner || true`; any pid gets `kill -TERM`, and 40 seconds later `pgrep` prints nothing; `docker ps -aq --filter label=nemar.runner=<runner id>` and, if it lists ids, `docker rm --force --volumes <ids>`.
5. Stop the tunnel's and the stack's detached sessions (`tmux kill-session -t <name>`, or the recorded pids with `kill -TERM`); `curl -s -m 5 http://127.0.0.1:8787/ ; echo rc=$?` reports a connection failure.
6. `rm -rf <operator scratch>/dm15/stack <operator scratch>/dm15/cfg && test ! -e <operator scratch>/dm15/stack && test ! -e <operator scratch>/dm15/cfg && echo state-deleted`.
7. On `$WS_DEMO`: `nice -n 19 ionice -c 3 rm -rf "${RUNNER_ROOT:?}" ~/.config/nemar-runner && test ! -e "${RUNNER_ROOT:?}" && test ! -e ~/.config/nemar-runner && echo runner-root-deleted`.
8. Write `<operator scratch>/s0/README.txt`: the time of each step, the revoke answer's state (no secret), the three confirmations, and step 1b's reading with the GPU visibility finding (yes, no, or not seen).
The implementer may choose: nothing else.

## Acceptance
