## Goal

The image containing `nemar-floor-zarr` is identified by one digest and verified (signed CI image under Q3 option A, or, at the fallback, an operator-built unsigned image with a written label), and the demo workstation can run it from that digest within its resource limits.

## Context

- Owner decision: the owner merges nemar-process PR #17 (epic C) and `feature/runner-epic` (once DM-13 is in it) into `main`; CI then publishes and signs. The workflow publishes only from `main` or an `image-nemar-python-v*` tag, refuses commits not on `origin/main`, and requires a `version` input on dispatch; `gh workflow run --ref <branch>` runs only its tests. You never merge or publish.
- Signing identity, exactly the workflow's `SIGNING_IDENTITY`: `^https://github\.com/nemarOrg/nemar-process/\.github/workflows/image-nemar-python\.yml@refs/(tags/image-nemar-python-v[0-9]+\.[0-9]+\.[0-9]+|heads/main)$`.
- The manager gives `$WS_DEMO` (the alias of DM-01's demo workstation) and `$RUNNER_ROOT` (a directory under that host's Q1 scratch path). Workstation steps run only after Q12 is answered yes.
- Fallback gate: if no signed digest passes step A3 by 2026-11-14T08:00 Pacific, run path B; if B cannot finish by 2026-11-14T12:00, stop (F2 and F3 take over).

## Scope

Read-only on GitHub. On the demo workstation: only `$RUNNER_ROOT/sif/` and the runtime's own image cache, after Q12.

## Decided design

Settled. Path A (plan of record):
A1. `gh run list -R nemarOrg/nemar-process --workflow image-nemar-python.yml --branch main --limit 3 --json databaseId,headSha,conclusion,event`: the newest `success` whose `headSha` contains DM-13's merge (`git -C $NEMAR_PROCESS merge-base --is-ancestor <DM-13 merge sha> <headSha>`). If none started, ask the owner (Q3 follow-up) to run `gh workflow run image-nemar-python.yml -R nemarOrg/nemar-process --ref main -f version=<the owner's version>`.
A2. `gh api repos/nemarOrg/nemar-process/actions/runs/<id>/artifacts --jq '.artifacts[].name'` includes `nemar-python-digests`; `gh run download <id> -R nemarOrg/nemar-process -n nemar-python-digests -D <operator scratch>/dm14`; read the OCI digest `<hex>` and the SIF reference from the JSON.
A3. `crane digest ghcr.io/nemarorg/nemar-python:<version>-cpu` equals `sha256:<hex>`; `cosign verify ghcr.io/nemarorg/nemar-python@sha256:<hex> --certificate-identity-regexp '<SIGNING_IDENTITY above>' --certificate-oidc-issuer https://token.actions.githubusercontent.com` passes; the same for the SIF reference.
Path B (fallback, labeled):
B1. Build host: the demo workstation if DM-01 found Docker or Podman there (Q12 must include building), else the operator's machine with `docker buildx build --platform linux/amd64 -f images/nemar-python/Dockerfile -t localhost/nemar-python:unsigned --load .` in a nemar-process checkout at the `feature/runner-epic` head containing DM-13; record that commit.
B2. `<hex>` is the image id: `docker inspect --format '{{.Id}}' localhost/nemar-python:unsigned`; the reference is `localhost/nemar-python@sha256:<hex>`; write `<operator scratch>/dm14/LABEL.txt` with the one line `unsigned, operator-built from nemarOrg/nemar-process@<commit>, image id sha256:<hex>, built <UTC time>`.
B3. For Apptainer: `docker save localhost/nemar-python:unsigned -o <operator scratch>/dm14/image.tar`, copy it with `scp` to `$WS_DEMO:$RUNNER_ROOT/sif/`, then build `$RUNNER_ROOT/sif/<hex>.sif` from `docker-archive://` and delete the tar.
Both paths, on `$WS_DEMO` after Q12, with the runtime of DM-01's verdict:
C1. Smoke test with limits: `apptainer exec --memory 256M --cpus 1 docker://docker.io/library/python:3.12-slim@sha256:b18b261e1b4974b4f321451ad5251ded85abb22c2b8b262da527dda1d031ab30 python3 -c 'print(1)'` (Docker or Podman: `run --rm --memory 256m --cpus 1 <same image> python3 -c 'print(1)'`); record pass or fail and whether limits applied.
C2. Path A under Apptainer: `apptainer pull $RUNNER_ROOT/sif/.<hex>.sif.part <SIF reference> && mv $RUNNER_ROOT/sif/.<hex>.sif.part $RUNNER_ROOT/sif/<hex>.sif`; under Docker or Podman: `<runtime> pull ghcr.io/nemarorg/nemar-python@sha256:<hex>`.
C3. `apptainer exec $RUNNER_ROOT/sif/<hex>.sif nemar-recipe version` (or `<runtime> run --rm <reference> nemar-recipe version`) piped to `python3 -c 'import json,sys; v=json.load(sys.stdin); assert v["recipes"]["nemar-floor-zarr"] == "1.0.0", v; assert v["eegprep"] == "0.5.0", v; print("ok")'`.
The implementer may choose: nothing else.
