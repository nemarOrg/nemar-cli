## Decided design

Settled, in order:
1. In the worktree: record `git rev-parse HEAD`.
2. Stack: `bun backend/scripts/compute-local-stack.ts serve --state <operator scratch>/dm15/stack --image <DM-14 reference> --seed-from-catalog <DM-02 id>`, detached; wait for the banner.
3. Tunnel, detached: `ssh -N -o ExitOnForwardFailure=yes -R 127.0.0.1:8787:127.0.0.1:8787 -R 127.0.0.1:8788:127.0.0.1:8788 "$WS_DEMO"`. If DM-01 recorded TCP forwarding "no", stop (cut-line item 3 needs Bun installed there, which is a separate owner decision).
4. On `$WS_DEMO`: `python3 -c 'import sys; assert sys.version_info >= (3, 9)'` (else stop); `git clone --depth 1 --branch feature/runner-epic https://github.com/nemarOrg/nemar-process "$RUNNER_ROOT/src"` and check its head equals the epic head; write `~/.config/nemar-runner/config.json` with `api_base` `http://127.0.0.1:8787`, `root` `$RUNNER_ROOT`, `sif_root` `$RUNNER_ROOT/sif`, `runtime` (DM-01's verdict), `slots` 1, `arch` `amd64`, `max_scratch_gb` (step 5's scratch), mode 0600.
5. Register with the owner key: `bun run src/index.ts admin compute runners register demo-1 --pool cpu --cores <C> --memory-mb <M> --gpus 0 --scratch-gb <S> --backend local --runtime <verdict> --arch amd64 --site lab_demo --trust lab --json`, where C = max(1, min(16, cores - 2)), M = floor(memory GiB x 1024 / 2), S = min(200, floor(scratch free GiB / 2)), and on the conversion host instead C = min(C, 4), M = floor(memory GiB x 1024 / 4), S = min(50, floor(scratch free GiB / 10)); pipe ONLY the secret field over ssh into `~/.config/nemar-runner/secret` under `umask 077`.
6. On `$WS_DEMO`: `python3 -I -S -c 'import runpy, sys; sys.path.insert(0, sys.argv[1]); runpy.run_module("nemar_runner", run_name="__main__", alter_sys=True)' "$RUNNER_ROOT/src/runner" doctor` prints yes for every required line.
7. Dispatch: `bun run src/index.ts admin compute pipeline run nemar-floor-zarr --dataset <id>@<version> --executor runner --json`; record the job id and time.
8. On `$WS_DEMO`: the step-6 command with `once` in place of `doctor`, in the foreground.
9. Gates: G5 `bun run src/index.ts admin compute jobs record <job> --json`; G6 `bun backend/scripts/compute-local-stack.ts outputs --state <operator scratch>/dm15/stack --job <job> --to <operator scratch>/dm15/out`, then `uv run --group signaljourney python scripts/validate_signaljourney.py <the signalJourney file>` in a nemar-process checkout at the epic head; G7 on `$WS_DEMO` `find "$RUNNER_ROOT/jobs" -mindepth 1 | wc -l` and `grep -c scratch_discarded "$RUNNER_ROOT/runner.log"`; G8 as DM-19 step 5.
10. Keep the stack, tunnel and registration until the demo ends; write `<operator scratch>/dm15/README.txt` with the commits, digest or label, job id, times and gate outputs.
The implementer may choose: nothing else; a failed step stops the card.
