## Goal

The launcher, booted the way `tapisjob_app.sh` boots it, runs a job to completion on a host with no Tapis or SLURM variables, sends the job's lease with every callback when one is given, applies Apptainer resource limits when told to, and every Tapis behavior and test stays as it was.

## Context

- Repository nemarOrg/nemar-process, base `feature/runner-epic` (cut from `feature/issue-1-epic-process`). Read `docs/launcher.md`, `docs/contracts.md`, `launcher/nemar_launch/` (`__main__.py`, `codes.py`, `run.py`, `spec.py`, the upload module), `launcher/tapisjob_app.sh` (its `boot` line: `python -I` ignores `PYTHONPATH`, so the launcher directory is put on `sys.path` by `runpy`), `tests/launcher/`, `tests/e2e/test_floor_launch.py`, `tests/standin/`.
- Today the launcher exits 13 without `_tapisExecSystemOutputDir`, reads `SLURM_JOB_END_TIME` for `time_limit`, `SLURM_JOB_ID` for provenance and `SLURM_TMPDIR` or `TMPDIR` for scratch.
- `X-Compute-Lease` is declared in nemar-cli's `shared/contract/compute-runner.ts` (DM-04); mirror it in `codes.py` with a comment naming the source.

## Decided design

Settled:
- Output directory: `_tapisExecSystemOutputDir`, else `NEMAR_OUTPUT_DIR`; neither is the existing exit 13 with its detail word.
- Deadline: `SLURM_JOB_END_TIME`, else `NEMAR_JOB_END_TIME` (integer epoch seconds); a malformed value is treated as absent, as today.
- Scratch: `SLURM_TMPDIR`, else `NEMAR_SCRATCH_DIR`, else `TMPDIR`.
- Lease: when `NEMAR_LEASE_ID` matches `^[0-9a-f]{32}$`, every bundle, outputs and outputs-complete call adds `X-Compute-Lease`; a malformed value ends at start with exit 13 and the existing configuration detail word.
- Limits: when `NEMAR_ENFORCE_LIMITS=1`, the Apptainer argv gains `--cpus <cores>` and `--memory <memory_mb>M` from the launch specification (`--memory` only when `memory_mb` is set); unset, the argv is byte-identical to today's.
- Provenance keeps `slurm_job_id` null when `SLURM_JOB_ID` is unset; nothing new is written into provenance.
- `docs/launcher.md` documents the runner's start: `python3 -I -S -c 'import runpy, sys; sys.path.insert(0, sys.argv[1]); runpy.run_module("nemar_launch", run_name="__main__", alter_sys=True)' <launcher directory>`, the line `tapisjob_app.sh` already uses.
The implementer may choose: where the environment is read (one function is preferred), test names.
