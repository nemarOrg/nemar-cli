## Goal

An owner can register, list and revoke a runner from the CLI; a registration secret buys a 15-minute access token and nothing else; both prefixes are refused by every other path; revoking a runner, or ending its registering owner, ends its tokens and its work in one batch.

## Decided design

Settled:
- Migration 0140 (header comment per column, never-NULL CHECKs, fixed-word shapes, no cascading foreign key, `IN` lists copied from `shared/compute-state.ts` and compared by a test):
  `compute_runners (id, name, pool, cores, memory_mb, gpus, scratch_gb, backend, runtimes TEXT, arch, accounting, site, trust, secret_hash UNIQUE, registered_by INTEGER NOT NULL, registered_at, revoked_at, revoke_reason, last_seen_at, runner_version)` with a partial unique index on `name WHERE revoked_at IS NULL`;
  `compute_runner_tokens (token_hash PRIMARY KEY, runner_id, expires_at, created_at)` with an index on `runner_id`;
  `compute_jobs` gains `executor TEXT NOT NULL DEFAULT 'tapis' CHECK (executor IN ('tapis','runner'))`, `accounting TEXT NOT NULL DEFAULT 'su' CHECK (accounting IN ('su','none'))`, a CHECK that `executor = 'runner' OR accounting = 'su'`, and `runner_backend`, `runner_id`, `runner_claimed_at`, `lease_id`, `lease_expires_at`, `claim_attempts INTEGER NOT NULL DEFAULT 0`, `runner_remote_id`, `runner_wall_seconds`, `runner_cpu_seconds`, `runner_max_rss_mb`; partial index `compute_jobs_runner_waiting ON compute_jobs (pool, created_at) WHERE executor = 'runner' AND state = 'created' AND runner_claimed_at IS NULL`. No `admitted_at` (that is #2121 P3's).
- `computeRunnersEnabled(env)`: `computeEnabled(env)` AND `COMPUTE_RUNNERS_ENABLED` exactly `"1"`, read at call time; the flag test adds the name to the absent list.
- Registration (owner only): `POST /admin/compute/runners`; `accounting: "su"` is refused `runner_accounting_unbuilt`; secret = prefix + 32 random bytes hex; only its SHA-256 is stored; an audit row `compute.runner.registered` (shape only). `GET /admin/compute/runners` lists without hashes.
- Revoke: `POST /admin/compute/runners/:id/revoke` runs `runnerRevokeStatements(runnerId, reason)` in one batch: set `revoked_at` and `revoke_reason`; delete its tokens; for its jobs with `runner_claimed_at` set and `started_at` NULL, clear the claim and lease; for its started live jobs, clear the lease and move them to `unreported` (D4 then decides them).
- Exchange: `POST /compute/runners/token` with `Authorization: Bearer nmr_...` and `RunnerTokenRequestSchema`; one answer `runner_unknown` for an unknown or revoked secret; `protocol_unsupported` for another protocol; `runners_disabled` when the switch is off; one token row (900 s, D1's clock); updates `last_seen_at` and `runner_version`.
- Both `authMiddleware` and `resolveApiKeyUser` refuse a bearer starting `nmr_` or `nmra_` with 401 `runner_credential_not_accepted` before any lookup, next to the `nmo_` refusal; `runnerAccess` accepts only an unexpired `nmra_` of an unrevoked runner; `GET /compute/runners/me` answers the runner's id, name and capacity.
- Cascade: `runnerEndStatements(userId, reason)` is `runnerRevokeStatements` for every unrevoked registration with `registered_by = userId`, plain `?` placeholders; `RUNNER_END_CALLERS` lists the real function names of `finalizeRevocation`, `tombstoneUserCascade` and the demotion handler; a source-scan test holds it; the docblock says a key revocation and a sign-out are deliberately not callers.
- CLI: `nemar admin compute runners register <name> --pool --cores --memory-mb --gpus --scratch-gb --backend --runtime (repeatable) --arch --site --trust [--json]`, `list [--json]`, `revoke <id> [--json]`; the secret printed once with a warning to keep it in a mode-0600 file; help with an "Exit codes:" block.
The implementer may choose: other internal names, test layout.
