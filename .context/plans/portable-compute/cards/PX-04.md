## Goal

`clean_asr` can hand back the calibration state it used, the state round-trips through plain JSON exactly, and reapplying a saved state to the same data gives `numpy.array_equal` output, so nemar-ica can store ASR's state beside its record and anyone can reproduce the cleaned data.

## Context

- Repository sccn/eegprep, branch `develop`. Read `src/eegprep/plugins/clean_rawdata/clean_asr.py` (calibrates with `asr_calibrate`, or `asr_calibrate_r` when `useriemannian == 'all'`, then processes with `asr_process` or `asr_process_r` on a signal extrapolated at its end, and discards the state), `asr_calibrate.py` (the state: `M`, `T`, `B`, `A`, `sos`, `iir_state`, `cov`, `carry`, `last_R`, `last_trivial`, `useriemannian`, `compatibility`), `asr_process.py` (what it reads from the state and the state it returns), `asr_calibrate_r.py`, `asr_process_r.py`, and `tests/test_clean_asr.py`, `tests/test_riemannian_asr.py`.
- nemar-process issue #5 names the state `{M, T, B, A, sos}` plus the sampling rate and channel order; eegprep's own state has more keys, and all of the calibration state is kept.

## Scope

- `src/eegprep/plugins/clean_rawdata/clean_asr.py`; a new `src/eegprep/plugins/clean_rawdata/asr_state.py`; new `tests/test_asr_state.py`; the ASR docs page if one lists `clean_asr`'s arguments.

## Decided design

Settled:
1. `clean_asr(EEG, ..., return_state=False, state=None)`. With `return_state=True` it returns `(EEG, asr_state)`; with the default it returns `EEG` as today (every current caller unchanged). With `state=` given it skips the reference selection and calibration and processes with that state.
2. `asr_state` is the calibration state as `asr_calibrate` (or `asr_calibrate_r`) returned it, before processing touched it, plus `srate`, `channels` (the channel labels in data order), and the processing arguments `cutoff`, `window_len`, `step_size`, `max_dims`, `useriemannian`, `maxmem`, and `format: "eegprep.asr-state.v1"`.
3. `asr_state.py` has `state_to_json(state) -> dict` (every array as `{"dtype": "float64", "shape": [...], "data": nested lists}`, `None` kept as `null`, numbers as Python floats so `json.dumps` writes the shortest round-trip text) and `state_from_json(document) -> dict` (refuses another `format`, a shape that does not match its data, a non-finite number, or a missing key, each with a `ValueError` naming the key).
4. Reapplying refuses a state whose `srate` or `channels` differ from the EEG it is given (`ValueError`), because a state from another montage would silently mix the wrong channels.
5. Reproduction: `clean_asr(EEG, return_state=True)` then `clean_asr(EEG, state=state_from_json(json.loads(json.dumps(state_to_json(state)))))` gives `numpy.array_equal` data, for the default path and for `useriemannian='calib'`; for `useriemannian='all'` too if its calibration state is a plain dictionary of arrays (else the test documents why that variant is excluded and `return_state` raises `NotImplementedError` for it).
The implementer may choose: helper names, the test's data (eegprep's `sample_data/eeglab_data.set` or a slice of it).

## Acceptance

- `uv run --no-sync pytest tests/test_asr_state.py -q` passes with: the `array_equal` reproduction of step 5 through a JSON round trip; a state whose `channels` are reordered is refused; a JSON document with one array element changed reproduces different data (the state is really used); the default call still returns a single EEG.
- Each new test fails under a one-line mutation (listed in the report), for example reapplying ignores `state` and recalibrates.

- The change would alter `clean_asr`'s output for callers that pass neither new argument: stop.
