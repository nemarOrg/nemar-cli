# ADR 0120: Reviewable pull requests are reviewed regardless of owner role

**Status:** accepted
**Date:** 2026-11-14
**Owner:** Seyed Yahya Shirazi

Supersedes the owner/administrator exemption in [ADR 0107](0107-dataset-pull-requests-are-screened-on-content-owners-and-administrators-are-exempt-and-the-review-check-is-required.md). The exact re-pull waiver in [ADR 0117](0117-an-upstream-re-pulls-own-pull-request-is-waived-from-the-review-by-nemars-record.md) remains.

## Context

The automatic review skipped a pull request when its author was a NEMAR owner or administrator. That kept owners from receiving the same independent review feedback as other contributors. The owner decided that review should run for everyone, with the narrowly recorded upstream re-pull waiver retained.

## Decision

**Run the automated review for every otherwise reviewable non-bot pull request, regardless of author or sender role. Waive only the exact upstream re-pull head identified by the record-bound rule in ADR 0117.**

The existing privacy eligibility fence, bot exclusion, contributor block, exact-head review behavior and mirror-record checks do not change. The queue reports an unreviewed owner or administrator pull request as `not_reviewed`; the legacy `exempt` wire value remains for compatibility but is not generated by current intake or queue code.

The explicit `nemar admin pr-reviews allow ... --admin` naming-rule operation is separate and retains its existing, audited behavior; this ADR removes the automatic identity-based exemption, not that manually invoked naming override. The one-time owner exception for the private, unpublished nm000569 PDF-removal merge is not a general review or merge-policy change.

## Consequences

- Owner and administrator pull requests on eligible datasets incur the same bounded review flow and receive the same check and report as other non-bot pull requests.
- Queue and detail reads no longer query GitHub repository roles to decide whether an author is exempt.
- The exact record-bound re-pull waiver remains the only automatic skipped review check. Existing dataset privacy and review gates remain in force.
- The separate manual naming-rule override may still post a skipped check when an administrator explicitly invokes it; changing that tool's semantics would be a separate decision.

## Alternatives considered

- **Keep the identity exemption:** rejected because it withholds review feedback from owners and administrators.
- **Remove the published-dataset privacy fence:** rejected; it is independent of author role and protects private or unpublished dataset content from review transmission.
- **Waive reviews based on a release branch name:** rejected; only the exact NEMAR record and matching head in ADR 0117 can establish a re-pull waiver.
